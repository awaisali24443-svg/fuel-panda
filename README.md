> **Pakistan's On-Demand Emergency Roadside Fuel Dispatch Platform** — Tailored specifically for Pakistani motorists, highway travelers, and daily commuters across Karachi, Lahore, Islamabad, Rawalpindi, and the National Motorway Network (M-2, M-9, GT Road). Connects stranded drivers with verified couriers equipped with OGRA-certified sealed Jerry Cans.

## 🇵🇰 Why Fuel Panda is Perfect for Pakistani Users

### 1. 💰 Real Pakistani Fuel Pricing & PKR Currency
- Real-time station prices in **Pakistani Rupees (PKR / Rs.)**:
  - **Super Petrol (Mogas 92 Octane)**: Rs. 265.50 / Litre (Bikes CD70/CG125, Suzuki Alto, Mehran, Cultus, Corolla, City)
  - **HOBC / Hi-Octane (97 Octane)**: Rs. 284.00 / Litre (Civic Turbo, Fortuner, Sportage, German luxury sedans)
  - **High-Speed Diesel (Euro-5 HSD)**: Rs. 273.80 / Litre (Toyota Revo / Hilux, Hiace, Shahzore, Commercial 4x4)
  - **Battery Jumpstart & EV Quick Rescue**: Rs. 1,200 (Heavy booster cables for dead AGS/Osaka/Phoenix lead-acid batteries)
- Transparent courier fees in PKR (Rs. 350 - Rs. 600) with refundable OGRA Jerry Can deposits.

### 2. 🇵🇰 Pakistan Official Emergency Helplines (One-Touch Dialing)
- **130** — **National Highway & Motorway Police (NH&MP)**: 24/7 breakdown escort on M-2, M-9, M-3, M-5, and GT Road.
- **1122** — **Punjab & Sindh Rescue Emergency Service**: Medical and roadside emergency dispatch.
- **15** — **Police Madadgar Helpline**: City-wide emergency assistance.
- **115** — **Edhi Foundation Ambulance Service**: Nationwide roadside emergency support.

### 3. 💳 Pakistani Payment Methods
- **Cash on Delivery (COD / نقدی ادائیگی)**: Hand-to-hand PKR notes upon fuel dispensing with exact change reminders.
- **JazzCash (جاز کیش)**: Instant transfer via mobile number or QR code scan.
- **Easypaisa (ایزی پیسہ)**: Instant Raast / Easypaisa mobile account settlement.
- **SadaPay / NayaPay / Raast**: Zero-fee instant digital bank transfers.

### 4. 🌐 Bilingual Support (English & اردو) & Roman Urdu Chat
- Instant language toggle (**English | اردو**) with localized Urdu headings, labels, and safety instructions.
- Pre-built Roman Urdu and Urdu quick-reply chips for fast roadside negotiation:
  - *"Bhai kitna time lagay ga? Jaldi pohnchain (بھائی کتنا وقت لگے گا؟)"*
  - *"Car hazards are ON, standing safely on shoulder lane (گاڑی کے ہیزرڈ آن ہیں)"*
  - *"JazzCash / Easypaisa or Cash on Delivery ready (جاز کیش / کیش تیار ہے)"*
  - *"Please bring OGRA sealed safety canister, no open bottles (سیل بند کین لانا)"*

### 5. 📲 WhatsApp Instant Location SOS
- One-click **"WhatsApp SOS"** button generates an emergency message containing live GPS coordinates, Google Maps pin link, vehicle plate number, and emergency condition to send directly to emergency contacts or riders.

### 6. 🛡️ OGRA Anti-Bottle Safety & 4-Digit Security Handshake OTP
- Strict adherence to OGRA and Civil Defence safety: **strictly NO open plastic bottles or siphoning**. All deliveries use certified steel/HDPE Jerry Cans with grounded safety spouts.
- 4-digit verification OTP prevents fraud: rider cannot dispense fuel until the stranded motorist confirms the code displayed on their phone.

### 7. 🚨 Highway Hazard Strobe Beacon
- Fullscreen alternating amber flasher turns the phone into an emergency strobe light to place on the rear windshield on M-2 or M-9 shoulders.
- Direct quick-dial link to **Motorway Police (130)** right inside the beacon view.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v18+)
- npm or pnpm or yarn

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/awaisali24443-svg/fuel-panda.git
cd fuel-panda

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Build optimized static distribution
npm run build

# Preview build locally
npm run preview
```
